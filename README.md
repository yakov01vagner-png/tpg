# TPG

Текстовая мобильная RPG-песочница в духе Mount & Blade: тёмное фэнтези, открытый
мир, пять королевств, подробная экономика. Дизайн — [DESIGN.md](DESIGN.md),
текущий план работ — [PLAN.md](PLAN.md).

Сейчас играбелен первый срез: создание персонажа через биографию, город со
списком дел, работа, наставники, испытания на магический ранг, рост навыков.

## Как запустить

Нужен [Node.js](https://nodejs.org) версии 20 или новее — это программа, на
которой всё работает. Скачай LTS-версию (на Windows — «Windows Installer
(.msi)») и поставь с настройками по умолчанию. После установки **закрой и снова
открой терминал**: переменная PATH обновляется только в новых окнах, иначе
команда `npm` так и не найдётся. Проверить: `node -v`.

Дальше один раз:

```
git clone https://github.com/yakov01vagner-png/tpg.git
cd tpg
npm install
```

Если репозиторий скачан zip-архивом с GitHub, `git clone` не нужен — просто
распакуй, зайди в папку и выполни `npm install`.

### В браузере (проще всего, телефон не нужен)

```
npm run web
```

Откроется страница в браузере. Окно лучше сузить до ширины телефона — вёрстка
рассчитана на портрет.

### На телефоне

1. Поставь на телефон **Expo Go** — бесплатное приложение из Google Play или
   App Store. Оно запускает проекты на Expo без сборки и установки APK.
2. На компьютере:

   ```
   npm run mobile
   ```

   В терминале появится QR-код.
3. Телефон и компьютер должны быть **в одной Wi-Fi сети**.
4. Android: открой Expo Go и нажми «Scan QR code».
   iOS: наведи обычную камеру на QR-код и нажми на всплывшую подсказку.

Игра скачается с твоего компьютера и запустится. Правки в коде подхватываются
на лету, перезапускать ничего не надо.

Проводной компьютер и телефон по Wi-Fi — это **одна сеть**, если кабель идёт в
тот же роутер, который раздаёт Wi-Fi. Так что обычно всё работает.

При первом запуске Windows спросит про брандмауэр — доступ Node.js к сети надо
**разрешить**, хотя бы для частных сетей, иначе телефон не достучится до
компьютера.

Если роутеры всё-таки разные (например, телефон сидит на мобильном интернете)
или сеть запрещает устройствам видеть друг друга, запусти через туннель —
медленнее на старте, но работает откуда угодно:

```
npm run mobile -- --tunnel
```

## Разработка

```
npm test         тесты ядра (vitest)
npm run typecheck
npm run lint     biome
npm run format   biome с автоисправлением
```

Правила репозитория — [CLAUDE.md](CLAUDE.md). Коротко: игровая логика живёт
только в `packages/engine`, приложение `apps/mobile` её не дублирует.

```
packages/engine   ядро симуляции, чистый TypeScript, запускается и в Node
apps/mobile       приложение на Expo (React Native)
```
